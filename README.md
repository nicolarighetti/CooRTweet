# CooRTweet
*[Nicola Righetti](https://github.com/nicolarighetti), [Paul Balluff](https://github.com/mrwunderbar666)*

Coordinated behavior is a relevant social media strategy employed for political astroturfing (Keller et al., 2020), the spread of inappropriate content online (Giglietto et al., 2020), and activism. Software for academic research and investigative journalism has been developed in the last few years to detect coordinated behavior, such as the [CooRnet R package](https://github.com/fabiogiglietto/CooRnet) (Giglietto, Righetti, Rossi, 2020), which detects Coordinated Link Sharing Behavior (CLSB) and Coordinated Image Sharing on Facebook and Instagram ([CooRnet website](http://coornet.org)), and the [Coordination Network Toolkit](https://github.com/QUT-Digital-Observatory/coordination-network-toolkit/blob/main/README.md) by Timothy Graham (Graham, QUT Digital Observatory, 2020).

The **CooRTweet** package builds on the existing literature on coordinated behavior and the experience of previous software, particularly CooRnet, to provide R users with an easy-to-use tool to detect various coordinated networks on Twitter and any other social media. It further opens up the possibility of cross-platform analysis. 

# Install

## Install from CRAN

```r
install.packages("CooRTweet")
```

# Quick Start

The package is compatible with any data, provided that it is formatted appropriately. It offers comprehensive support for data obtained from the Twitter Academic API in the JSON format. This format is generated by the function `get_all_tweets` from the R package [academictwitteR](https://github.com/cjbarrie/academictwitteR), which simultaneously retrieves tweets and user information. Additionally, the simple function `prep_data` aids in formatting the data as required by the package.

`prep_data()` removes incomplete and duplicate shares by default. Set
`drop_na = FALSE` or `drop_duplicates = FALSE` to retain them.

`detect_groups()` can select pairs within one inclusive interval of time
differences. For example, `time_window_low = 10, time_window = 30` includes
pairs shared exactly 10 or 30 seconds apart, as well as those between them.
The lower limit defaults to 0.

For a walk-through of the development version, see the [vignette source](https://github.com/nicolarighetti/CooRTweet/blob/master/vignettes/vignette.Rmd).

`generate_coordinated_network()` returns edges above the median edge weight by default (`subgraph = 1`). Set `subgraph = 0` to return the full network with threshold indicators on its edges.

## German elections data

The **installed package includes** `german_elections_sample`, a 97,413-row
anonymized temporal excerpt for URL and image coordination examples. It is not
representative of the full campaign and cannot reproduce the paper's figures.
Load it with `data("german_elections_sample", package = "CooRTweet")`.

The **full anonymized dataset is not included in the installed package**. The
same data previously distributed as `german_elections` is now available only in
the source repository as [data-raw/german_elections_full.rda](data-raw/german_elections_full.rda).
From the root of a repository checkout, load it with:

```r
load("data-raw/german_elections_full.rda") # creates german_elections
```

Use this full dataset with the [paper reproduction script](vignettes/reproduce_examples.Rmd).
The script is kept in the source repository under `vignettes/`, but is not
included in the installed package or built as a package vignette. Some plot
panels require non-public data and remain commented out in the public script.

## Coordinated Sharing Detection Service powered by CooRTweet

CooRTweet also powers the [Coordinated Sharing Detection Service](https://coortweet.lab.atc.gr/), a web-based service built on a streamlined version of the R package. It enables data journalists, fact-checkers, researchers, and other practitioners to analyze and visualize patterns of coordinated sharing in social media data.
